# Paradise Nursery

A React plant shop with an 18-plant catalog and a Redux Toolkit shopping cart. Browse three collections, add plants, adjust quantities, and view line totals and the order total. Checkout displays a coming-soon message.

## Run locally

Install dependencies with `npm install`, then run `npm run dev`. Use `npm run build` for a production build. Plant photographs use the image URLs from IBM Skills Network’s e-plantShopping starter catalog and require internet access.
